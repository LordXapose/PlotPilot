Data Analysis Toolkit v2 — User Guide

16-module browser-based statistical workbench. No installation. No coding required. All data stays in your browser.

Explorer

Load any CSV, inspect column types, view missing values, preview rows. Click "Load CSV" in the header to use your own data.

Data Cleaning

Impute missing values (mean/median/mode/zero/forward fill), detect outliers by IQR or Z-score, normalize or standardize columns, filter rows by condition, discretize into bins.

Descriptive Stats

Mean, median, SD, variance, skewness, kurtosis, IQR, CV, SEM, five-number summary, frequency table, histogram. Full multi-column summary table via button.

Visualizations

8 chart types: histogram (adjustable bins), scatter (shows Pearson r live), box plot, bar chart, line chart, correlation matrix (with r labels), bubble chart, area chart.

Distributions

Normal, Exponential, Uniform, Binomial, Poisson, Student t. Live PDF and CDF with parameter sliders. KS goodness-of-fit test with Q-Q plot.

Statistical Inference

Confidence intervals (80-99%), one-sample t-test, two-sample Welch t-test with Cohen's d, normality test (Jarque-Bera + Shapiro-Wilk).

ANOVA

One-way ANOVA with F-table, SS, MS, eta-squared effect size. Tukey HSD post-hoc pairwise comparisons. Group means chart.

Regression

Simple OLS: equation, R-squared, RMSE, coefficient table with p-values, scatter with regression line, residuals vs fitted, prediction interval.

Multiple Regression

Select multiple predictors via checkboxes. Full OLS coefficient table with t-stats, p-values, VIF (multicollinearity check), AIC, BIC, fitted vs actual and residual plots.

Time Series

Moving average, exponential smoothing, linear trend (slope and direction), ACF bar chart, rolling statistics, ADF stationarity approximation.

Sampling & Power

CLT interactive demo, bootstrap CI for mean/median/SD, sample size calculator (mean and proportion), power curves by effect size.

Chi-Squared

Independence test on two categorical columns. Contingency table with observed and expected frequencies. Cramer's V effect size.

Probability Calculator

P(X <= x), P(X >= x), P(a <= X <= b), inverse CDF for all 6 distributions. Chart updates live with parameters.

Data Story

One-click auto-insights: skewness warnings, outlier alerts, correlation flags, missing value report, normality check, distribution summary.

p-value guide

  • p < 0.001 — very strong evidence against H0
  • 0.001 - 0.01 — strong evidence
  • 0.01 - 0.05 — moderate evidence (reject at alpha=0.05)
  • 0.05 - 0.10 — weak / marginal
  • >= 0.10 — little evidence against H0
