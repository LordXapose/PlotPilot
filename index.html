Data Analysis Toolkit — User Guide

A self-contained, browser-based statistical workbench. No installation, no server, no coding required. All calculations run locally in your browser.

Data Explorer

Load and inspect your dataset. Supports CSV and TSV files. The toolkit auto-detects column types and flags missing values.

Features

  • Upload CSV via Load CSV button
  • Visual missing-value bars per column
  • Column schema: type, unique count, missing count
  • Scrollable data preview (first 10 rows)
  • Export current data as CSV

Descriptive Statistics

Full summary statistics for any numeric column: mean, median, mode, SD, variance, skewness, kurtosis, IQR, CV, SEM, and more.

Interpretation tips

  • |Skewness| > 1: noticeably skewed distribution
  • Kurtosis > 2: heavier tails than normal
  • CV > 30%: high relative variability
  • Mean ≠ Median: likely skewed or outliers present

Visualizations

  • Histogram: distribution shape of one variable (adjust bins)
  • Scatter: relationship between two numeric variables
  • Box plot: five-number summary + outliers per group
  • Bar chart: category frequencies
  • Correlation matrix: pairwise Pearson r for all numeric columns

Probability Distributions

Visualize PDF and CDF for Normal, Exponential, Uniform, Binomial, Poisson, and Student t distributions. Parameters adjust in real time.

The Goodness-of-Fit panel runs a Kolmogorov-Smirnov test: if D < D_critical, your data is consistent with the chosen distribution.

Statistical Inference

  • Confidence interval: range for the true mean at chosen level (80%–99%)
  • One-sample t-test: test if mean equals a specified value
  • Two-sample t-test: compare means of two groups (Welch's)
  • Normality test: Jarque-Bera + Shapiro-Wilk approximation

p-value guide

p-valueInterpretation
< 0.001Very strong evidence against H₀
0.001–0.01Strong evidence
0.01–0.05Moderate evidence (reject at α=0.05)
0.05–0.10Weak / marginal
≥ 0.10Little evidence against H₀

Regression

Fits ordinary-least-squares (OLS) simple linear regression. Outputs slope, intercept, R², RMSE, F-statistic, and p-values for each coefficient. Includes residual vs fitted plot and prediction with intervals.

Probability Calculator

Compute exact probabilities for any supported distribution:

  • P(X ≤ x) — left-tail probability (CDF)
  • P(X ≥ x) — right-tail probability
  • P(a ≤ X ≤ b) — interval probability
  • Inverse CDF: find x such that P(X ≤ x) = p
